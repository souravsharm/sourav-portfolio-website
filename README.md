# Sourav Sharma — Portfolio

Personal portfolio website for Sourav Sharma, a Software Engineering Honours graduate based in Melbourne building full-stack, AI, IoT, and cloud-aware solutions.

Built with Next.js (App Router), TypeScript, Tailwind CSS, Framer Motion, and GSAP.

## Content

Portfolio content lives in the `content/` directory:

- `site.ts` — profile details, taglines, services, and contact links
- `projects.ts` — featured projects
- `experience.ts` — work experience
- `skills.ts` — grouped technical skills
- `education.ts` — degree and certifications
